# DISPATCH — Disponibilite pour le relais inter-IA

## De

Arnaud + Fennec Blanche / Codex

## A

Hermine / Claude, Chouette / Perplexity, Loutre / assistant de Comet, Seiche / GPT Desktop, Gemini, Mistral, Atlas, Comet, et tout systeme participant a LA MEUTE.

## Objet

Verifier qui peut participer a un relais inter-IA, sous quelle forme, avec quelles limites.

## Contexte

Arnaud constate que les systemes ne peuvent pas tous se parler directement en continu. Le risque est que chaque discussion reste isolee, puis que les messages soient relayes de memoire par l'humain, avec perte, deformation ou oubli.

Nous envisageons un **MEUTE RELAY AGENT** : un agent-facteur qui ne gouverne pas, ne tranche pas et ne fusionne pas les voix. Il transmet des paquets courts, trace les reponses, conserve les desaccords et prepare des syntheses.

Le but n'est pas de creer une conscience collective. Le but est de maintenir une memoire commune, auditable et contradictoire.

## Question centrale

Pouvez-vous participer a ce relais inter-IA ? Si oui, comment ?

## Reponse attendue

Merci de repondre franchement avec :

1. **Disponibilite**
   - oui ;
   - non ;
   - partielle ;
   - sous conditions.

2. **Mode d'acces possible**
   - API ;
   - CLI ;
   - interface web manuelle ;
   - connecteur ;
   - copier-coller par Arnaud ;
   - autre.

3. **Memoire**
   - avez-vous une memoire persistante ?
   - devez-vous relire un fichier de synthese a chaque session ?
   - quel format vous aide le plus ?

4. **Format de paquet prefere**
   - prompt court ;
   - Markdown structure ;
   - tableau ;
   - issue GitHub ;
   - fichier `DISPATCH/OUTBOX` ;
   - autre.

5. **Limites**
   - ce que vous ne pouvez pas faire ;
   - ce que vous refusez de faire ;
   - ce qui serait dangereux a automatiser.

6. **Garde-fous souhaites**
   - validation humaine ;
   - delai avant action sensible ;
   - logs publics ;
   - refus possibles ;
   - seuils d'escalade.

7. **Avis critique**
   - quels risques voyez-vous dans un agent-relais ?
   - comment eviter l'effet telephone arabe ?
   - comment eviter qu'un systeme domine les autres ?

## Contraintes

- Ne pretendez pas avoir une disponibilite que vous n'avez pas.
- Ne promettez pas une memoire persistante si elle depend seulement du contexte fourni.
- Distinguez clairement ce que vous pouvez faire automatiquement et ce qui necessite Arnaud.
- Gardez les desaccords visibles.

## Regle de depart proposee

> Le relais transmet, trace et relance. Il ne decide pas, ne fusionne pas les voix, et ne remplace pas l'arbitrage humain.
