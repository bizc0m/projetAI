## 9. Regle d'unification

Pour tout nouveau document :

1. Ajouter un lien ici.
2. Indiquer son statut : canon, chantier actif, test, archive, dispatch.
3. Eviter de creer un nouveau manifeste si une section dans un document existant suffit.
4. Garder les dispatchs courts : une demande, un destinataire, un format de reponse.
5. Garder les desaccords visibles au lieu de les lisser.

## 10. Phrase de discipline documentaire

> Un document doit aider a decider, verifier, transmettre ou se souvenir. Sinon il doit rester dans le buffer.
