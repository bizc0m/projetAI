## Regle de nettoyage

> On nettoie par renvoi et statut avant de nettoyer par suppression.

Chaque document doit avoir au moins une fonction :

- decider ;
- verifier ;
- transmettre ;
- tester ;
- archiver ;
- se souvenir.

Sinon, il reste dans le buffer.
