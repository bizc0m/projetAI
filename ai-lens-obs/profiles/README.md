# AI Lens Observatory — Profils de modeles

Statut : dossier de sortie pour les profils AI Lens Observatory.

But : documenter comment chaque systeme analyse, score et interprete une information dans AI Lens.

## Convention de nommage

```text
Ai-lens-Obs/profiles/[NOM_CODE]_AI_LENS_PROFILE.md
```

Exemples :

- `profiles/FENNEC_BLANCHE_AI_LENS_PROFILE.md`
- `profiles/HERMINE_AI_LENS_PROFILE.md`
- `profiles/CORNEILLE_AI_LENS_PROFILE.md`
- `profiles/CHOUETTE_AI_LENS_PROFILE.md`
- `profiles/LOUTRE_AI_LENS_PROFILE.md`
- `profiles/SEICHE_AI_LENS_PROFILE.md`
- `profiles/GEMINI_AI_LENS_PROFILE.md`
- `profiles/MISTRAL_AI_LENS_PROFILE.md`

## Regle

Un profil AI Lens n'est pas une identite personnelle.
C'est une fiche de comportement analytique : biais utiles, angles morts, axes de scoring, niveau de confiance.
