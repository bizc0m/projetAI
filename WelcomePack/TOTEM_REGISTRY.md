## How to Use This Registry

### For Individual Invocation
```
1. Find your totem in the table above
2. Note the LLM (Claude Opus, GPT-4o, o1, etc.)
3. Run: ritual [TOTEM_NAME] "your question"
4. Get response from that totem's LLM
```

### For Collective Invocation (TIER 1)
```
1. Run: ritual TIER1 "your question"
2. All 8 TIER 1 totems analyze in parallel
3. Receive all 8 responses
4. See consensus + divergence
```

### For Cross-Totem Debate
```
1. Invoke GAIA: ritual GAIA "Should we mine here?"
2. GAIA says: "No. Boundaries crossed."
3. Request: ritual GAÏA "Ask EROS what she thinks"
4. GAÏA invokes EROS and reports back
5. Debate structure maintained within single chat
```

## Invoke Commands Cheat Sheet

```bash
# Single totem
ritual GAIA "question"
ritual CHRONOS "question"
ritual EROS "question"

# All TIER 1
ritual TIER1 "question"

# Specific subset
ritual GAIA,CHRONOS,THÉMIS "question"

ritual GAIA "question" --verbose --save-log --cross-invoke

ritual --list

ritual GAIA --profile

ritual --status
```
